# js/bash

Early version of the command-syntax parser (bash-style), the predecessor of the
pytool parser. Retained for reference; not imported anywhere at runtime — the
live parser is `js/pytool/pytool_parser.js`.

- `command.pegjs` — grammar
- `command_parser.js` — generated by Peggy (do not edit)
- `test_command_parser.html` — manual test page
