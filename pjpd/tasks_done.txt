Implement the delegated task harness per docs/TASK_DELEGATION_SPEC.md. The harness is bound to a single task docmem for its lifetime and always looks there for work. Tasks are nodes in a tree; the harness picks the next task in depth-first preorder that is not a summary node and not done, seeds an AgentLoop with the task path (ancestor and earlier-sibling context) plus the task's read-set, and runs it. Agents treat the task node as around-advice: they may create child task nodes then call suspend() so the child is picked up next, or defer a task by moving its node and suspending. A finished task is folded into an inserted summary node. Task state (status, attempts, failures, model override) lives in a {key=value, ...} block in the task node text, interpreted by agents, so the format is loose with common key names and integer values. Replaces delegate() and complete() with suspend().
